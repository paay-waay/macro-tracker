# 宏量 3.2.2

在线使用：https://paay-waay.github.io/macro-tracker/

每餐可填写食物名称，方便之后回看；名称选填，热量（kcal）和蛋白质（g）必填。首页显示当日热量剩余与蛋白质进度，并可直接记录或修改当天体重；回顾页保留周进度、体重趋势和历史。常用餐、碳水、脂肪输入仍隐藏。

数据保存在当前设备的浏览器中。旧记录里的名称、碳水、脂肪和常用餐数据仍保留在 IndexedDB、完整 JSON 备份和 CSV 导出中；编辑旧记录的名称、热量或蛋白质不会清掉其他字段。新记录的碳水与脂肪保持空值，不会伪造为零。换设备前请从「设置 → 备份与数据」导出完整 JSON 备份。

这是无需构建的静态 GitHub Pages 应用。把此文件夹内的全部文件上传至仓库根目录，覆盖同名文件；不要上传整个文件夹或 ZIP。`index.html` 引用 3.2.2 的独立 JS/CSS 文件；旧版资源保留给可能尚未更新的缓存页面。不要删除旧资源或清除网站数据。
