# 宏量 3.1.0

## 上传

1. 在目前 App 设置里导出完整 JSON 备份。
2. 把这个文件夹**里面的全部文件**一次性上传到 `paay-waay/macro-tracker` 仓库根目录，覆盖同名文件。不要上传 ZIP，也不要把整个文件夹嵌套进仓库。
3. `index.html` 保持在原位置。等待 GitHub Actions 的 Pages 部署成功，再用原网址、原浏览器或原主屏幕 App 联网打开。必要时关闭后重新打开；不要清除网站数据。
4. 核对历史、常吃和目标。

网址保持 `https://paay-waay.github.io/macro-tracker/`，Pages 发布设置不需要改变。

## 这版的日常流程

- 点「记一餐」，直接填写热量、蛋白质、碳水、脂肪，保存。名称可选。
- 勾选「存为常吃」，下次在首页点一次就记入。没有常吃时，会显示最近吃过的食物。
- 点已记录的一行可直接改四项数值或删除。误操作可撤销。
- 不再选择份数、来源或估算模式，不再创建称重配方。
- 首页显示热量已用 / 目标 / 剩余、蛋白进度，以及碳水和脂肪累计值。
- 「今天记完了」用于区分整天摄入与部分记录。周均值只统计记全的日期。
- 设置默认只显示每日目标；备份、导入、历史草稿和恢复快照折叠在「备份与数据」。

## 兼容与离线

沿用 `macro-tracker-v13` 版本 2、`minimal_v3_state` 和原始备份键。3.0 数据直接读取，2.x 数据沿用原有迁移流程。旧记录、C/F、常吃、目标、草稿、原始快照和配方明细均不主动删除；旧配方只作为已有常吃的宏量数值复用，没有配方编辑入口。旧常吃有上次份量时，沿用当时实际使用的宏量值。

新版资源采用 `*-3.1.0.js` / `styles-3.1.0.css` 独立文件名。原 `app.js`、`styles.css`、`core.js`、`storage.js` 留作 3.0 缓存页面的兼容资源，请一起上传。不要手工删除旧缓存或数据库。后续新增版本应继续使用新的资源文件名。

首次联网完成后可离线记录。数据仍保存在本机；换设备需导入备份。发布文件夹不含个人记录或测试数据。

按要求禁用页面手势缩放，输入框不会因小字号触发自动放大；浏览器或系统强制辅助缩放不受网页完全控制。手机键盘布局已加入可见视口适配，实体 iPhone 的手势、键盘和主屏幕行为仍以设备实测为准。
